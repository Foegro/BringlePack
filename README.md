# BringlePack
A balatro mod, which adds Bringle themed cards to the game

Mod made by Foegro

Art made by KevinE.S.The Lost Knight


In case you somehow stumbled upon this mod without knowing who Bringle is: https://www.youtube.com/@BringlesCan

Join the Bringle Discord: https://discord.com/invite/bringle

How to install:
1. Install [Steamodded](https://github.com/Steamodded/smods)
(Guide for installing Steamodded: https://github.com/Steamodded/smods/wiki)
2. Put this mod into the Mods folder, like you did with Steamodded
